# Infrastructure-Flood-Risk-Exposure-Mapping-GIS-

This project demonstrates spatial risk-exposure identification using publicly available infrastructure and hazard datasets. Minnesota power plant locations from the U.S. Energy Information Administration (EIA) were mapped against FEMA National Flood Hazard Layer (NFHL) flood-risk polygons using QGIS.
A spatial intersection analysis was performed to identify facilities located within flood-risk zones. The workflow illustrates how infrastructure location data, environmental hazard datasets, and GIS tools can be combined to support enterprise risk awareness, infrastructure resilience planning, and early-stage exposure screening.
Tools used:
QGIS
FEMA NFHL GIS data
EIA power plant dataset
Outputs include a flood-exposure dataset and a map visualization.
